## How to Add Images

1. Create a folder called `images` in the repository
2. Add your 3 images with these filenames:
   - `image1.jpg` (coaching session)
   - `image2.jpg` (goalkeeper coaching)
   - `image3.jpg` (team session)

## GitHub Pages Setup

3. Select "main" branch as source
